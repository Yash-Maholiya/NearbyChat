🛡️ Zero-Knowledge Relay

Device C only reads the envelope header (recipient fingerprint and TTL). Because the message body is encrypted with Alice and Bob's shared key, Device C cannot read, log, or tamper with the conversation.

🔄 TTL & Loop Prevention

Each multi-hop packet carries a Time-to-Live (TTL = 3). Device C decrements the TTL by 1 before relaying. If a packet loops back, Device C's seen-cache drops it immediately, preventing broadcast storms.

🔏 Authentication & Tamper-Proofing

The AES-GCM 128-bit MAC tag includes the sender, recipient, and timestamp as Additional Authenticated Data (AAD). If a malicious relay modifies even a single bit of the packet, Bob's phone discards it.
