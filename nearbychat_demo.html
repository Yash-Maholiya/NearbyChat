🔑

X25519 Key Agreement

Each device generates an X25519 static identity keypair stored in hardware-backed storage. Static ECDH establishes the foundation for mutual authentication without any centralized server.

✨

Perfect Forward Secrecy (PFS)

Every message generates a single-use ephemeral keypair. Even if a long-term device key is compromised in the future, past historical messages cannot be decrypted because ephemeral keys are wiped from RAM.

🔒

AES-GCM-256 & AAD

Plaintexts are encrypted with AES-GCM using unique 12-byte random nonces. Additional Authenticated Data (AAD) binds envelope headers (version, messageId, claimed username, sender public key) to prevent tampering.

✓

Cryptographically Verified ACKs

Delivery receipts are authenticated via HMAC-SHA256(messageKey, "ack:" + messageId). Only the true holder of the message key can generate a valid receipt, eliminating fake delivery status attacks.

🛡️

Mutual Safety Number

A 6-byte hex sequence derived via HKDF-SHA256 from the static ECDH secret and lexicographically sorted public keys. Users compare this sequence out-of-band to guarantee zero Man-in-the-Middle.

💾

Encrypted Storage at Rest

Local chat history is encrypted with AES-GCM-256 using a master key derived from the OS Keystore. Decrypted messages never sit in plaintext on flash memory.
