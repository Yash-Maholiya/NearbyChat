📡

BLE Discovery

Each phone advertises as a GATT peripheral (NC-Alice, NC-Bob). The other phone scans, connects, and reads the identity characteristic to learn the username and public key.

🔑

X25519 Key Agreement

Each device generates an X25519 keypair on first launch, stored in the OS secure enclave. Keys are exchanged over BLE. The shared secret never leaves either device.

🔒

AES-GCM-256

Every message is encrypted with AES-GCM using a key derived from the X25519 shared secret. The authentication tag ensures tampering is detected and rejected.

🛡️

Safety Number

A 6-byte SHA-256 fingerprint of the shared secret. Both users compare it in person to confirm no man-in-the-middle has substituted a key during discovery.

💾

On-Device History

Messages are stored locally on the device using encrypted shared preferences. No cloud, no sync, no server. History persists across app restarts.

🚫

Zero Infrastructure

No servers, no accounts, no phone numbers, no internet. Works in disaster zones, remote areas, or any environment where connectivity is unavailable or censored.
